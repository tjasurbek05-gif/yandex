# STYLE FORMULA (approved, byte-identical into every asset)

Flat vector minimalism with soft long shadows and smooth color gradients; clean rounded rectangles
and simple geometric shapes, no outlines, a single gentle top-light highlight on each block.
Background a calm vertical gradient sky that slowly shifts hue with height; the stacked tower blocks
cycle through a smooth pastel-to-vivid spectrum so each new block contrasts the last, while
perfect-stack flashes and coins use a bright warm gold signal glow. Soft, satisfying, modern
mobile-puzzle mood, gentle ambient light. High contrast between blocks and sky, clean readable
silhouettes, consistent flat frontal perspective across all elements.
